# 나의 서재 (My Reading Log)

읽은 책을 한 권씩 기록하는 **단일 파일 독서 기록 웹앱**입니다.
`index.html` 하나에 HTML·CSS·JavaScript가 모두 들어 있어, 인터넷 없이도 그대로 동작하고 외부 CDN이나 서버가 필요 없습니다.

## 주요 기능

- **내 서재** — 총 읽은 책/올해 읽은 책 요약, 제목·저자·메모 실시간 검색, 연도·분야 필터, 표지 색상과 별점이 있는 책 카드
- **책 추가·수정·삭제** — 제목(필수), 저자, 완독일, 0.5점 단위 별점, 분야(7종), 표지 색상(8종), 한줄평·인상 깊은 문장
- **월별 통계** — 연도 전환, 총 권수·월 평균·평균 별점·최다 월, 연간/월간 목표 달성률, 1~12월 인터랙티브 막대 차트(막대를 누르면 그 달의 책 목록), 분야별 분포
- **저장과 백업** — 브라우저 `localStorage`에 자동 저장(키: `my_reading_log_v1`), JSON 내보내기/가져오기, 전체 초기화
- **첫 화면 안내** — 기록이 없을 때 `첫 책 기록하기`와 `예시 데이터 3권 넣어보기` 제공

## 아이폰에서 홈 화면에 추가

배포 위치: GitHub Pages (`didi` 저장소, `main` 브랜치 루트)

1. Safari로 아래 주소를 엽니다.
   `https://iamdayeon87-prog.github.io/didi/`
2. 하단 **공유** 버튼 → **홈 화면에 추가** → 이름을 확인하고 **추가**.
3. 홈 화면 아이콘으로 열면 브라우저 주소창 없이 앱처럼 실행됩니다.

기록은 그 기기의 브라우저 저장소에 남습니다. 기기를 바꾸거나 저장 공간을 비울 때를 대비해 **설정(톱니바퀴) → JSON 내보내기**로 백업해 두세요.

## 테스트

- `tests/run.html` — 코어 로직(46항목 이상), 화면 동작, PWA 설정을 한 번에 검사합니다. 저장소를 클론한 뒤 정적 서버(예: `python3 -m http.server`)로 열면 됩니다.
