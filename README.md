# 나만의 서재 (My Reading Log)

읽은 책을 **표지 그리드**로 모으는 단일 파일 독서 기록 웹앱입니다.
`index.html` 하나에 HTML·CSS·JavaScript가 모두 들어 있어, 인터넷 없이도 그대로 동작하고 외부 CDN이나 서버가 필요 없습니다.

## 주요 기능

- **3×3 표지 그리드** — 세로형 표지(2:3)를 3열로 배치. 표지 사진이 없으면 선택한 색상 + 제목 미니 커버로 표시됩니다.
- **완독 순 정렬** — 완독일 최신순이 기본. 목록 위 `완독 최신순 / 오래된순` 버튼으로 전환할 수 있습니다.
- **표지 위 인생책 하트** — 표지 왼쪽 아래 하트를 눌러 상세 화면에 들어가지 않고 바로 지정/해제합니다. 오른쪽 아래에는 완독 월(`YY-MM`) 배지가 붙습니다.
- **검색 · 필터** — 제목·저자·한 줄 평 검색, `전체 / 🩷 하트만 / 카테고리` 칩.
- **상단 세그먼트** — `서재 보기` ↔ `독서 통계` 전환(하단 탭바 없음).
- **독서 통계** — 총 완독·이번 달 완독·인생책 요약, 월별 완독 막대(누르면 그 달의 책 목록), 카테고리별 분포(누르면 서재로 이동).
- **책 등록·수정·삭제** — 제목(필수), 저자, 완독일(기본 오늘), 카테고리, 인생책 토글, 별점(0.5점 단위), 한 줄 평/메모.
- **표지 등록 4가지** — ① 아이폰 앨범 사진(최대 너비 360px JPEG로 압축해 저장) ② 이미지 URL ③ 제목으로 표지 검색(Google Books → Open Library, 온라인일 때) ④ 색상 표지 8종.
- **저장과 백업** — 브라우저 `localStorage`(키: `my_reading_log_v1`, 예전 버전 기록도 그대로 읽음), JSON 내보내기/가져오기, 전체 초기화. 설정은 헤더의 톱니바퀴 버튼.

## 아이폰에서 홈 화면에 추가

배포 위치: GitHub (`didi` 저장소, `main` 브랜치 루트)

1. Safari로 배포 주소(예: `https://raw.githack.com/iamdayeon87-prog/didi/main/index.html`)를 엽니다.
2. 하단 **공유** 버튼 → **홈 화면에 추가** → 이름을 확인하고 **추가**.
3. 홈 화면 아이콘으로 열면 브라우저 주소창 없이 앱처럼 실행됩니다.

기록은 그 기기의 브라우저 저장소에 남습니다. 기기를 바꾸거나 저장 공간을 비울 때를 대비해 **설정(톱니바퀴) → 파일로 저장**으로 JSON을 백업해 두세요.

## 테스트

- `tests/run.html` — 코어 로직·화면 동작·PWA 설정을 한 번에 검사합니다. 정적 서버(예: `python3 -m http.server`)로 저장소를 열고 `/tests/run.html`을 방문하면 됩니다.

## 구조

```
index.html          앱 전체 (HTML + CSS + JS, 외부 의존 없음)
tests/run.html      테스트 실행 페이지
tests/core.test.js  로직 테스트
tests/ui.test.js    화면 동작 테스트
```
